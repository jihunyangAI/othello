# 오델로 게임 기획서(GDD)

## 1. 목표와 범위

웹 브라우저에서 같은 기기를 사용하는 두 사람이 번갈아 플레이하는 오델로 게임을 만든다. MVP는 한 화면에서 게임 시작, 착수, 승패 확인, 새 게임까지 지원한다.

AI 대전, 온라인 대전, 계정, 저장 및 불러오기, 무르기, 제한 시간은 제외한다. 페이지를 새로고침하면 진행 상황을 복원하지 않고 새 게임을 시작한다.

## 2. 보드와 초기 상태

- 보드는 8×8칸이다. 열은 왼쪽부터 A~H, 행은 위쪽부터 1~8이며 좌상단은 A1이다.
- 백돌은 D4·E5, 흑돌은 E4·D5에 배치하고 나머지 칸은 비운다.
- 흑이 선공이다. 점수는 보드의 실제 돌 수이며 초기에는 흑 2개, 백 2개이다.

## 3. 게임 규칙

### 착수와 뒤집기

- 자신의 차례에 빈칸 하나를 선택한다.
- 선택한 칸에서 가로·세로·대각선의 8방향 중 적어도 한 방향에 상대 돌이 하나 이상 연속으로 있고, 그 바로 다음 칸에 자기 돌이 있으면 합법수이다. 사이에 빈칸이나 보드 경계가 있으면 그 방향에서는 포획할 수 없다.
- 합법수에 돌을 놓으면 조건을 만족하는 모든 방향의 상대 돌을 전부 자기 색으로 뒤집는다. 일부 방향만 선택할 수 없다.
- 뒤집힌 돌을 출발점으로 추가 포획하는 연쇄 반전은 하지 않는다.
- 이미 돌이 있는 칸이나 상대 돌을 포획하지 못하는 칸의 선택은 무효다. 보드·점수·차례를 유지하고 안내를 표시한다.
- 착수와 뒤집기를 하나의 동작으로 처리하며 처리 중 반복 입력으로 중복 착수하지 않는다.

### 차례, 자동 패스와 종료

착수와 뒤집기 후 양쪽의 합법수를 계산하여 다음 순서로 처리한다.

1. 양쪽 모두 합법수가 없으면 종료한다. 보드가 가득 찬 경우도 포함한다.
2. 상대에게 합법수가 있으면 상대 차례로 바꾼다.
3. 상대에게 합법수가 없고 착수한 플레이어에게만 있으면 상대 차례를 자동 패스한다. 패스된 색을 안내하고 같은 플레이어가 계속 둔다.

합법수가 있으면 임의로 패스할 수 없다. 종료 후 추가 착수는 허용하지 않는다. 최종 실제 돌 수가 많은 쪽이 승리하며 같으면 무승부다. 남은 빈칸은 점수에 더하지 않는다.

## 4. 화면과 조작

- 좌표, 돌, 현재 차례의 합법수, 현재 차례, 흑·백 돌 수를 표시한다. 돌·합법수·선택 초점은 색상 외의 모양이나 테두리로도 구분한다.
- 패스 안내와 종료 결과(승자 또는 무승부, 최종 돌 수)를 표시한다. 종료 시 합법수 표시를 없앤다.
- 새 게임 버튼을 제공한다. 한 수 이상 진행된 게임은 초기화 확인을 표시한다. 확인하면 초기 상태로 돌아가고 취소하면 진행 상태를 유지한다. 초기 상태나 종료 후에는 확인 없이 시작한다. 새 게임에서는 이전 결과와 안내를 제거한다.
- 마우스와 모바일 터치로 동일한 기능을 제공한다. 작은 화면에서도 보드 전체와 핵심 조작을 사용할 수 있어야 한다.
- 키보드만으로 보드와 새 게임 버튼에 접근할 수 있어야 한다. 보드에서는 방향키로 칸을 이동하고 Enter 또는 Space로 착수한다. 초점을 표시하며 보드 경계에서는 좌표를 순환시키지 않는다.
- 보드와 각 칸에 접근 가능한 이름을 제공하여 좌표, 돌의 색 또는 빈칸 여부를 알 수 있게 한다. 차례 변경·무효 입력·패스·결과 안내는 보조 기술에서도 확인할 수 있어야 한다.

## 5. AI 확장을 위한 구현 원칙

보드 상태, 합법수·포획 계산, 착수 결과, 차례·패스·종료 판정을 화면 표시와 입력 처리에서 분리한다. 같은 상태와 착수에는 같은 규칙 결과가 나와야 한다.

추후 AI는 현재 상태에서 합법수 하나를 선택하는 역할로 추가한다. 사람과 AI가 동일한 착수 검증과 규칙 처리를 사용하도록 구성한다. 기술 스택과 AI 알고리즘은 이 문서에서 제한하지 않는다.

## 6. 수용 기준

| 번호 | 검증 상황 | 기대 결과 |
| --- | --- | --- |
| AC-01 | 첫 진입·새로고침·새 게임 | 중앙 4돌의 초기 배치, 흑 차례, 흑 2개·백 2개로 시작한다. |
| AC-02 | 초기 합법수 | C4·D3·E6·F5 네 곳만 표시된다. |
| AC-03 | 초기 흑 D3 착수 | D3에 흑돌을 놓고 D4를 뒤집는다. 흑 4개·백 1개, 백 차례가 된다. |
| AC-04 | 점유된 칸 또는 포획하지 못하는 빈칸 선택 | 안내만 표시하고 보드·점수·차례를 유지한다. |
| AC-05 | 여러 방향 포획 및 빈칸에 의한 차단 | 모든 직접 포획 방향을 뒤집되 빈칸·경계·자기 돌 너머의 돌은 뒤집지 않는다. |
| AC-06 | 뒤집힌 돌에서만 추가 포획 가능한 상태 | 추가 연쇄 반전하지 않는다. |
| AC-07 | 착수 후 상대만 합법수가 없는 상태 | 상대를 자동 패스하고 안내한다. 같은 플레이어가 계속 두며 합법수 표시를 갱신한다. 합법수가 있는 차례에는 임의 패스할 수 없다. |
| AC-08 | 빈칸이 남아도 양쪽 모두 합법수가 없는 상태 | 종료하고 실제 돌 수로 결과를 표시한다. 빈칸은 점수에 더하지 않는다. |
| AC-09 | 보드가 가득 찬 상태 및 최종 동률 | 종료하고 최종 돌 수와 승자 또는 무승부를 표시한다. |
| AC-10 | 종료 후 보드 선택 | 보드·점수·결과가 유지되며 합법수 표시가 없다. |
| AC-11 | 진행 중 새 게임 취소 및 확인 | 취소하면 진행 상태를 유지하고, 확인하면 초기 상태로 돌아간다. 초기 상태·종료 후 새 게임은 확인 없이 시작하며 이전 결과와 안내가 제거된다. |
| AC-12 | 빠른 반복 클릭·터치 | 한 번의 착수를 중복 반영하지 않고 차례와 돌 수를 규칙에 맞게 유지한다. |
| AC-13 | 모바일 터치와 키보드만으로 플레이 | 착수, 결과 확인, 새 게임이 가능하다. 방향키 초점과 Enter·Space 착수가 동작하며 보조 기술에서 상태 안내를 확인할 수 있다. |

## 7. 규칙 출처

기본 경기 규칙은 [세계 오델로 연맹(WOF) 공식 규칙](https://www.worldothello.org/about/about-othello/othello-rules/official-rules/english)을 기준으로 한다. 합법수 표시, 자동 패스 안내, 새 게임 확인과 접근성 조작은 이 웹 게임의 제품 요구사항이다.
